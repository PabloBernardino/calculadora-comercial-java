# 🧮 Calculadora Comercial Inteligente

Projeto desenvolvido em Java com o objetivo de praticar lógica de programação, estruturas condicionais, repetições e cálculos matemáticos.

---

# 🚀 Funcionalidades

A calculadora possui as seguintes operações:

- ✅ Soma
- ✅ Subtração
- ✅ Multiplicação
- ✅ Divisão
- ✅ Cálculo de desconto
- ✅ Juros simples
- ✅ Juros compostos
- ✅ Cálculo de IMC
- ✅ Média escolar

---

# 🛠 Tecnologias utilizadas

- Java
- IntelliJ IDEA
- Scanner
- Estruturas condicionais (`if`, `else`, `switch`)
- Estruturas de repetição (`do while`, `for`)
- Métodos matemáticos (`Math.pow()`)

---

# 📚 Conceitos praticados

Durante o desenvolvimento deste projeto foram praticados:

- Entrada e saída de dados
- Operadores matemáticos
- Estruturas condicionais
- Estruturas de repetição
- Validação de dados
- Tratamento de divisão por zero
